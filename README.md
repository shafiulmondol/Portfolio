# Shafiul Islam — Portfolio Website

Responsive personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — portfolio homepage
- `style.css` — styling, responsive layout, dark/light themes
- `script.js` — mobile navigation, theme toggle, footer year
- `cv.html` — CV page with a Print / Save as PDF button

## Run locally
Open `index.html` in your browser. No framework or build step is required.

## Before publishing
1. Replace every `YOUR_GITHUB_USERNAME` placeholder with your real GitHub username.
2. In `index.html` and `cv.html`, replace generic LinkedIn URLs with your profile.
3. Edit `cv.html` to add your real email, university, expected graduation date, verified skills, and achievements.
4. Replace project links with the actual repository links.
5. Review the CV carefully before sharing it with recruiters. It intentionally does not invent contact details or credentials.

## Publish with GitHub Pages
1. Create a repository named `yourusername.github.io`.
2. Upload all five files to the repository root.
3. Open **Settings → Pages** and select the `main` branch and `/ (root)` if prompted.
4. Your site should publish at `https://yourusername.github.io/`.

## Features
- Dark / light mode toggle; the selected theme is saved in `localStorage`.
- Responsive navigation and layouts.
- CV page at `cv.html`.
- Print / Save as PDF using the browser's print dialog.
